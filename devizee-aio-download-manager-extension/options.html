Devizee Extension Options

Passive Download Interception Threshold
Only downloads whose declared file size exceeds this threshold will be relayed to Devizee. Smaller downloads proceed in Chrome automatically.
Domain Exclusions
One domain per line. Downloads initiated from these hostnames will never be intercepted.
Desktop App Connection
Test whether Chrome Native Messaging host (`com.devizee.native_host`) is registered and communicating with Devizee.
